# DESPA OK – redesign homepage v5

Směr:

- současný evropský průmyslový web, ne marketingová landing page
- žádné card-grid dashboardy, ikonové benefity, pill badges, gradienty, glassmorphism ani obří claimy
- žádné sekční číslování ani brutalistická/award-site stylizace
- velká reálná fotografie produktu + normální popis pod ní
- výrobní program jako seznam kategorií a produktová galerie bez boxových „karet“
- novinky jako klasické redakční řádky s technickými údaji
- servis, firma a kontakt věcně, bez marketingových sloganů
- žlutá pouze jako firemní akcent

Technologie:

- Bootstrap 5.3.8 (layout/responsive utilities a offcanvas)
- IBM Plex Sans + IBM Plex Sans Condensed
- vanilla JavaScript

Obsah a fotografie vycházejí z veřejného webu DESPA OK a z dodaných podkladů.
Koncept je určen pouze jako neoficiální redesign / obchodní ukázka.
